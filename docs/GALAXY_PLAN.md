# The Galaxy engine port (Keen 4, 5 and 6) — plan

SIM-G-01 in the ledger: the Galaxy engine ported from omnispeak upstream (`omnispeak-ref/src`), running
headless through each episode's built-in demo. This file splits that unit into checkable pieces, fixes the
file order and the conventions, and is the brief for anyone (person or agent) porting a piece.

## Unit checks

- **SIM-G-01a (spec).** Every tile (8x8 and 16x16, masked and unmasked), every picture, masked picture and
  sprite (all four shifts) and every font string drawn through the library onto the emulated EGA card reads
  back pixel-identical to `GalData`'s own decode of the same chunk. Fades and palette writes reach the card's
  palette. Test: `godot/tests/simg01a_draw.gd`.
- **SIM-G-01b (spec).** The refresh manager over a loaded map: scrolling in all directions draws the same
  picture as drawing the map's tiles directly at that origin; sprites placed, moved and erased leave the
  background exact; animated tiles step as TILEINFO says.
- **SIM-G-01c (spec).** The 70 Hz tic clock with the original's catch-up rule; demo files from EGAGRAPH play
  their recorded control structures frame by frame; the text window and menu routines draw.
- **SIM-G-01d to h (spec, then oracle).** Each episode's built-in demos run to their end without a script
  error, Keen ending where the demo leaves him. The oracle comparison against DOSBox recordings is REPLAY-G4/5/6.

## Conventions (A10, A2, A11, A13 applied to omnispeak)

1. **One class, many scripts.** `GalLib` (gal_lib.gd) extends `RefCounted`; each later script extends the one
   before: GalLib → GalRF → GalIO → GalUS → **GalCK** → GalAct → GalPlay → GalGame → GalKeen4 / GalKeen5 /
   GalKeen6 (each episode class extends GalGame). Each script ports whole C files, named in its header.
2. **Names.** Every function, global and constant keeps omnispeak's name (`CK_PhysUpdateNormalObj`,
   `RF_PlaceSprite`, `ck_gameState`). Static helpers of a C file keep their names too, unless another C file
   has a different static function of the same name: then the later script's copy gets the C file as a suffix
   (`CK_Foo_ck4obj2`) and a comment says so (one class means one namespace).
3. **Forward calls: gal_ck.gd.** `GalCK` declares the game layer once: the structs (`CK_object`,
   `CK_action`, `CK_GameState`, `CK_keenState`, `CK_objPhysData`, `CK_EpisodeDef`), every constant of the
   headers, every global more than one C file uses, the variable/action tables (ck_act.c), and an untyped stub
   for every non-static function of ck_*.c and ck4/5/6_*.c, generated by `tools/gen_gal_decl.py` between the
   GENERATED markers. A later script defines the function with a typed signature of **the same number of
   parameters in the same order** (Godot 4.7 accepts typed overrides of untyped stubs, any return type). A stub
   reached at run time quits with "not ported yet: NAME". Globals only one C file uses are declared in that
   file's script; never redeclare a member an earlier script has (Godot refuses it).
4. **Function pointers.** Think, collide and draw functions, and every other function pointer, are
   `StringName`s called with `call()`: `obj->currentAction->think(obj)` is
   `call(obj.currentAction.think, obj)`; passing `CK_Fall` is passing `&"CK_Fall"`. NULL is `&""`. The actions
   come from the ACTION file through `CK_VAR_LoadVars`; `CK_ACT_MissingFunctions()` lists names no script defines.
5. **Structs and pointers.** Struct pointers are references to the inner-class instances (null for NULL);
   `obj->x` is `obj.x`. A struct copy (`*a = *b`) is `a.copy_from(b)`; a memset is `clear()`. The object
   list keeps omnispeak's linked-list order and free list; `obj.index` is the place in `ck_objArray` (C's pointer
   arithmetic). A pointer to an integer passed so the callee can write it (`&w`, `int16_t *`) becomes a return
   value: one value returned, several returned as a `PackedInt32Array` in parameter order, the doc comment says
   which. The 16-bit offsets C keeps in `user1..4` stay integers (`RF_AddSpriteDrawUsing16BitOffset` takes and
   returns the field).
6. **Arithmetic.** Whole numbers only. Every store wraps as the C type does: `uint16_t` fields (`posX`, `posY`,
   `timeUntillThink`, clip-rect units and tiles) with `u16()`, `int16_t` with `s16()`, `int32_t` with
   `s32()`, `uint8_t` with `u8()`; plain C `int` is 32-bit in omnispeak. C's integer promotions decide
   comparisons (a `uint16_t` compared with an `int` compares as int; `uint32_t` arithmetic wraps at 2^32).
   GDScript `/` and `%` on ints truncate toward zero as C does; `>>` on a negative int is arithmetic as in C.
7. **Macros.** `CK_INT(name, def)` → `CK_INT("name", def)`; `CK_CHUNKNUM(X)`/`CK_SOUNDNUM(X)` →
   `CK_CHUNKNUM("X")`/`CK_SOUNDNUM("X")`; `CK_ACTION(x)` → `CK_GetActionByName("x")`; `CK_STRING(x)` →
   `CK_STRING("x")`; `CK_CHUNKID(X)` → `"X"` (a `chunk_id_t` is the name; `CK_LookupChunk(id)` gives the
   number); `CK_INTELEMENT(n, i)`, `CK_STRINGELEMENT(n, i)`; `CT_CLASS(Item)` → `CT_CLASS("Item")`;
   `CK_FUNCTION(x)` → `CK_ACT_GetFunction("x")`; `ck_currentEpisode->ep` → `ck_currentEpisode_ep`;
   `CK_Cross_max/min` exist. Strings are `String`; `snprintf` becomes `%` formatting.
8. **Build flags.** The port is omnispeak's vanilla build: `CK_VANILLA` defined, so `QUICKSAVE_ENABLED`,
   `EXTRA_*_OPTIONS`, `CK_VAR_TYPECHECK`, `CK_ENABLE_PLAYLOOP_DUMPER`, `CK_RUN_ACTION_VALIDATOR`, `CK_DEBUG`,
   `CK_RAND_DEBUG` are not; `WITH_KEEN4/5/6` and `HAS_HELPSCREEN` are (episode checks at run time decide);
   `VL_EGA` is not (the port draws through omnispeak's 8-bit software surfaces). `#if 0` blocks are dropped.
9. **Time.** No wall clock. The tic counter is advanced by the machine's timer (`DosMachine`, reprogrammed to
   the original's rate by SD_Startup); waits are synchronous against the virtual clock (A11). A busy loop that
   waits for the clock or a key calls `IN_PumpEvents()` or `SD_WaitTick()` (each runs the machine to its next
   event) so it cannot spin forever.
10. **Drawing.** Through the library (`VL_*`, `VH_*`, `VHB_*`, `RF_*`) only, which reaches the `EgaCard` the way
    id_vl_dos.c drives the EGA.
11. **Randomness.** `US_RndT` over omnispeak's table, index in state.
12. **State.** Every variable that is game state is a plain member, so `state_snapshot()` (A6/A7) sees it;
    machine and data references are listed in `NOT_STATE`.
13. **Missing library functions.** A port that needs an id_* function the library scripts lack ports it from
    omnispeak into its own script under a heading `# ---- id_* functions the library lacks (move to the library)`
    and names it in its report; it does not edit another script.

## Order of work

SIM-G-01a first (everything draws through it), then b and c, then d-f, then Keen 4's objects (g) to run Keen 4's
demos, then Keen 5 and 6 (h). Each unit's check is written before the unit and joins `tools/regress.py`.
